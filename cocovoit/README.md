# AAW : Projets d'application Web
## **Cocovoit**

### Lancement du build
```powershell
npm run build
```

### Lancement du client
```powershell
npm run dev
```

### Lancement du server
```powershell
npm start
```
Lance le serveur avec nodemon. Toutes les modification relance le serveur automatiquement (Evite de l'arrêter et de le relancer manuellement)
